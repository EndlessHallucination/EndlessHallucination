## Latest project

### [DocPilot](https://github.com/EndlessHallucination/DocPilot) · [live →](https://pdf-copilot.netlify.app/)

Fill and sign any PDF in the browser, and get told field by field what to put
where and why — based on your own situation. Explanations in English, values in
the form's own language.

The form I built it for has **nine eligibility clauses and eight checkboxes** —
the printer left one off. So rather than hunting for boxes and asking about
those, it sends the model every line of text and lets it decide what the fields
are. Geometry only answers *where the mark goes*. The clause with no box still
gets an answer.

`React` `TypeScript` `Vite` `pdf.js` `pdf-lib` `zustand` `Tailwind` `Chrome extension` `Hebrew / RTL`
